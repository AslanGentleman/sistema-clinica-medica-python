# Sistema de Gestão de Clínica Médica & Atendimento (Python)

Sistema de Gestão Clínica desenvolvido em Python com menu interativo via terminal, manipulação de estruturas de dados (dicionários e listas), cálculo de estatísticas e implementação de algoritmo de **Fila de Atendimento FIFO (First In, First Out)**.

---

## 🚀 Funcionalidades

- **Cadastro de Pacientes:** Armazenamento estruturado de dados (Nome, Idade e Telefone).
- **Módulo de Estatísticas:** Cálculo automático de total de pacientes, média de idades e identificação de pacientes mais novos/velhos.
- **Filtro e Busca:** Busca dinâmica de pacientes por nome.
- **Gerenciamento de Fila de Espera:** Algoritmo de atendimento sequencial (FIFO) com remoção prioritária.

---

## 🛠️ Tecnologias e Conceitos

- **Python 3**
- **Estruturas de Dados:** Listas, Dicionários e Métodos de Fila (`append`, `pop`).
- **Gestão do Projeto:** Organizado via Trello (Kanban) abrangendo diagramação UML, tabelas verdade e desenvolvimento.
